# Piano B — Carta e penna

> Se Tako si ferma durante il servizio. Da stampare e tenere in cassa con un blocco comande.

## 1. Come accorgersi che Tako è fermo

Segnali sui dispositivi:
- I **tablet** mostrano stato **offline** o restano su caricamento, oppure una ricarica pagina non torna.
- I **QR ai tavoli** non aprono più il menu sul telefono del cliente (pagina che non carica).
- La **cucina (KDS)** non riceve più ticket nuovi.
- La **cassa** non apre conti nuovi o dà errore all'incasso.

Prima prova veloce (30 secondi):
1. Ricarica la pagina su un tablet.
2. Controlla che il **Mac di Tako sia acceso e sveglio** (schermo, alimentazione, cavo di rete).
3. Se il Mac è ok ma i tablet no → controlla il **wifi della sala**.
4. Se in 2 minuti non torna → **passa alla carta**. Non fermare il servizio.

---

## 2. Passare alle comande cartacee

Regola: **una comanda per tavolo, per portata.** Scrivi leggibile per la cucina.

Modello comanda (ricopia sul blocco):

```
┌─────────────────────────────────────────┐
│  COMANDA n° ____    Ora: ____:____       │
│  Tavolo: ____        Coperti: ____       │
├─────────────────────────────────────────┤
│  Qtà │ Piatto              │ Note        │
│  ─── │ ─────────────────── │ ─────────── │
│   __ │ ___________________ │ ___________ │
│   __ │ ___________________ │ ___________ │
│   __ │ ___________________ │ ___________ │
│   __ │ ___________________ │ ___________ │
│   __ │ ___________________ │ ___________ │
├─────────────────────────────────────────┤
│  Cameriere: __________                   │
└─────────────────────────────────────────┘
```

Flusso carta:
1. Cameriere scrive la comanda, **strappa e porta in cucina**.
2. La cucina lavora dall'alto verso il basso, poi spilla la comanda su un chiodo "fatto".
3. Tieni le comande di ogni tavolo **insieme** (spillate) fino al conto.

---

## 3. Gestire i conti a mano

1. Per ogni tavolo raccogli tutte le comande cartacee.
2. Somma i prezzi dal **menu cartaceo / listino** (tieni una copia in cassa).
3. Aggiungi il **coperto** (n° coperti × importo coperto del locale).
4. Scrivi il totale, incassa contanti/POS esterno, dai il resto.
5. Segna su un foglio "registro incassi carta": **tavolo · totale · metodo · ora**.
6. Questo registro serve dopo, per reinserire tutto in Tako.

Modello registro incassi:

```
Tavolo │ Totale │ Metodo (cont/carta) │ Coperti │ Ora
────── │ ────── │ ─────────────────── │ ─────── │ ─────
```

---

## 4. A fine servizio: reinserire in Tako

Sì, si può reinserire tutto a mano dalla dashboard. Usa la schermata **Comanda** e poi la **Cassa**.

Per ogni tavolo passato su carta:
1. Apri **Comanda** → scegli il **tavolo** → aggiungi i piatti con **+ / −** → **Invia comanda**.
   (Ripeti per ogni comanda cartacea di quel tavolo.)
2. La cucina la ignora se il servizio è finito: serve solo a registrare l'ordine nel sistema.
3. Vai in **Cassa** → il conto del tavolo si è popolato → apri il conto.
4. Scegli il metodo giusto (**Contanti / Carta / Digitale**), correggi i **coperti** se serve, tocca **Incassa**.
5. Spunta la riga sul registro carta. Passa al tavolo successivo.

Verifica finale:
- Confronta il totale "Incasso oggi" in **Cassa** con la somma del tuo registro carta.
- Se combaciano, hai reinserito tutto.

> Nota: la schermata **Comanda** è l'unico modo per inserire ordini a mano dalla dashboard.
> Non esiste una "comanda libera" senza tavolo/menu: i piatti vanno scelti dal menu del locale.
> Per l'asporto passato su carta, crea comunque un conto dalla Cassa (Nuovo conto) e registralo lì.

---

## 5. Chi chiamare se Tako non riparte

**Numero assistenza Tako: [_______________]**

Prima di chiamare, annota:
- I tablet sono offline o è solo la cassa?
- Il Mac di Tako è acceso e sveglio?
- Il wifi della sala funziona (altri dispositivi navigano)?
- Da che ora è fermo?

Nel frattempo: **continua a servire con la carta.** Il servizio non si ferma mai per un guasto software.
