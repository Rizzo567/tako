Configura il lavoro sull'intero sistema. Segnala esattamente quali accessi mancano per avviare API e DB: il clone non contiene password o dati vivi. A inizio e fine di ogni sessione applica il protocollo Git: status, fetch, aggiornamento sicuro, lettura contesto e decisioni; a fine sessione resoconto, verifica, commit e push del tuo branch.
